# IPL Data Analysis Dashboard - Quick Guide

## Features

1. **All Seasons Overview**
   - View total wins by all teams across seasons
   - Interactive bar charts of team performance

2. **Season Analysis**
   - Filter data by specific IPL season
   - Team performance statistics
   - Season-specific visualizations

3. **Player Analysis**
   - Top 10 batters by runs
   - Top 10 bowlers by wickets
   - Performance charts

4. **Venue Analysis**
   - Match statistics by venue
   - Team performance at specific grounds
   - Win percentages by location

5. **Head-to-Head Analysis**
   - Compare any two teams
   - Historical match results
   - Detailed match statistics

## How to Use

1. Double-click `start.bat` or run `.\start.bat` in PowerShell
2. The dashboard will open in your default web browser
3. Use the dropdowns to select seasons, teams, or venues
4. Interactive charts will update automatically

## Requirements
- matches.csv and deliveries.csv files in the project folder
- Python with required packages (automatically installed)
