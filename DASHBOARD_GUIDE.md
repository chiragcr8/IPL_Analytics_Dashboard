# IPL Dashboard User Guide

## Quick Start
1. Double-click `start.bat` or run `.\start.bat` in PowerShell
2. The dashboard will open in your web browser

## Main Features

### 1. Overview 📊
- Total wins by teams across all seasons
- Interactive bar charts showing team performance
- Season-wise comparisons

### 2. Season Analysis 📅
- Select any IPL season from the dropdown
- View detailed team performance for that season
- Season-specific statistics and trends

### 3. Player Analysis 🏏
- Top 10 Batters by runs scored
- Top 10 Bowlers by wickets taken
- Interactive player performance charts
- Filter by season and team

### 4. Venue Stats 📍
- Match statistics by venue
- Team performance at different grounds
- Interactive venue-specific visualizations

### 5. Head-to-Head Analysis 🤝
- Compare any two teams
- Historical match results
- Detailed match-by-match statistics
- Player performance in specific matches

### 6. Summary & Insights 📈
- Most successful teams by season
- Top performers (batters and bowlers)
- Overall tournament statistics
- Quick insights and trends

## Tips
- Use the sidebar for easy navigation
- Hover over charts for detailed information
- Use dropdowns to filter data
- Click on team names to see detailed statistics
